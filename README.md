# APPS — samostalne aplikacije AI sistema

Svaka aplikacija je **sopstveni git repo** unutar kategorije. `APPS/` je samo stablo
direktorijuma (nije git repo).

## Kategorije
- `utilities/` — opšte desktop alatke (npr. **oko** — snimanje ekrana)
- `security/` — bezbednost/kredencijali (npr. **sef** — password manager)
- `graphics/` — slika/vizuelno
- `productivity/` — produktivnost
- `development/` — razvojni alati
- `media/` — audio/video
- `system/` — sistemske alatke
- `network/` — mreža/servisi
- `ai/` — AI alati

Dev-logovi za rad na ovim aplikacijama (za sada) žive u `ai_workplace/.ai/dev-log`.
