## Global Constraints

- House edge 1%: `multiplier = 99 / chance`; chance ∈ [2.00, 98.00] (2 decimale); `over`: target = 100 − chance, win ako roll > target; `under`: target = chance, win ako roll < target.
- Ulog min `0.001`; početni balans `1000`; milestone pragovi 50/100/200/500 %.
- RNG: HMAC-SHA256(serverSeed, `clientSeed:nonce:round`), 4 bajta → uint32, odbaci ≥ 4.294.960.000, `(u % 10000)/100` (2 decimale, 10.000 ishoda; ispravljeno rulingom Task 3); `Math.random` zabranjen u engine-ima/workerima.
- Budžeti simulacije: `[1,5,10,20,50,100,200,500,1000,2000,5000,10000]`, 1000 sesija po budžetu, kraj sesije: bankrot (sledeći ulog > balans ili balans ≤ 0) ILI balans ≥ 1000× ILI `maxRoundsPerSession` (podrazumevano 200000). Tier pragovi: 1.5×, 2×, 5×, 10×, 1000×.
- Strategija JSON tačno kao spec §3.5 (`game, strategyName, type:'solo', createdAt, baseBet, targetValue, condition, winChance, maxBets, onLoss{action,value}, onWin{action,value}, stopConditions{takeProfit, stopLoss}`); ime fajla = `sanitizeName` (`[A-Za-z0-9_-]`, max 60, prazno → `Dice_Strategy_<YYYYMMDD-HHMMSS>`).
- Analiza: `data/dice/<ime>_analiza.json` (§3.6 polja). Preporuka balansa za ulog 1: `increase p%` → Σ_{i=0..L}(1+p/100)^i; `reset` → L+1.
- Auto-petlja uživo: u rendereru, kašnjenje 30–50 ms po krugu (`delayMs` parametar; smoke koristi 0). Worker-i: bez `setTimeout`.
- Smoke protokol iz Faze 1: svaka nova provera = ključ u `checks` (`dice_ui`, `stats`, `rng`, `dice_manual`, `dice_auto`, `strategy_io`, `sim_page`) → `<KEY> OK`.
- ES-moduli svuda (`"type":"module"`); preload ostaje CommonJS `preload.cjs` (sandbox).
