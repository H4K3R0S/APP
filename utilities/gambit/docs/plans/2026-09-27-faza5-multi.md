# Gambit Faza 5 — Multi-Strategy (koraci 23–25) — plan implementacije

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sekvencer za ulančavanje strategija (AKO loss streak ≥ X / balans padne ispod Y% ➔ PREBACI NA strategiju B, uz opcione akcije po igri), backend prenos stanja (balans i ulog se NE resetuju), hibridna Monte Carlo simulacija u radnicima i marker-grafikon sa višebojnom linijom i tooltip-om.

**Architecture:** `shared/hybrid_schema.js` (oblik hibridne konfiguracije + validacija), `main/simulator/hybrid.js` (stub → puna logika: `createHybrid(config).check(ctx)` vraća sledeću strategiju; `executeStateHandover` čuva balans/ulog), `session.js` već poziva `hybrid.check` posle svakog kruga i beleži `handovers`. Renderer: `src/js/sim/sequencer.js` (pod-tab na stranici Simulacije), `src/js/sim/hybrid_chart.js` (uPlot: serija po strategiji + vertikalni markeri + tooltip). Hibridna konfiguracija se čuva kao strategija `type:'multi'` u `data/<game>/` (Hub je lista u Fazi 6).

**Tech Stack:** kao ranije.

**Spec:** `docs/specs/2026-09-27-gambit-design.md` (§3.5 Multi, §3.6 handovers/representativeSession, §3.7 hibrid chart)

## Global Constraints

- Hibridna konfiguracija: `{ game, strategyName, type:'multi', createdAt, baseStrategy: <ime>, triggers: [ { when:'lossStreak'|'balanceDrop', value:number, switchTo:<ime>, actions:{ minesShift?:boolean, kenoSwapAnchors?:boolean, diceRaiseMultiplier?:boolean } } ] }`; okidači se proveravaju redom (prvi ispunjen pobeđuje), svaki okida najviše jednom po sesiji (bez ping-pong petlje); `balanceDrop` = balans < value % početnog budžeta; `lossStreak` = tekući niz gubitaka ≥ value.
- Handover (korak 24): `sessionBalance` i `currentBetAmount` ostaju; nova strategija nastavlja sa svojim pravilima (onLoss/onWin) od zatečenog uloga; `lossStreak` se resetuje; `globalBetCount` teče. Akcije: Mines → trenutna rotacija matrice po `shift.algo` nove strategije; Keno → zamena sidara sekundarnim (sledeća 3 po učestalosti); Dice → `targetValue` nove strategije (viši multiplikator je posledica izbora strategije).
- Radnik: `hybridConfig` u `workerData` sa REŠENIM strategijama (Main učitava sve JSON-e pre pokretanja: `{ base: obj, byName: {ime: obj} }`), `hybrid.reset()` po sesiji.
- Izveštaj: `representativeSession.handovers[] = {round, from, to, balance, bet, lossStreak}` + `series`; `overall.handoversAvg` (prosek prebacivanja po sesiji).
- Grafikon: linija profita u boji aktivne strategije (paleta: plava, narandžasta, ljubičasta, zelena…), vertikalna isprekidana linija na `round` svakog handover-a, tooltip: „Krug N: <razlog>. Aktivirana promena na <ime>. Balans sačuvan na X$“.
- Smoke ključevi: `SEQUENCER`, `SIM_HYBRID`.

## Review Focus

1. Okidač `switchTo` na strategiju iz DRUGE igre mora biti odbijen pri validaciji (hibrid je unutar iste igre) → Task 1 test.
2. Okidač koji pokazuje na nepostojeću strategiju → Main vraća `{error}` pre pokretanja radnika, ne pada radnik → Task 2 test (`resolveHybrid`).
3. Prebacivanje kad je zatečeni ulog veći od balansa nove strategije ne sme „resetovati“ ulog na bazu tiho: bankrot se proglašava po postojećim pravilima (`bet > balance`) → Task 2 test.
4. Više okidača ispunjenih u istom krugu → samo prvi po redu; isti okidač ne sme da okida ponovo (jednom po sesiji) → Task 2 test.
5. Sekvencer bez ijednog uslova → pokretanje se ponaša kao solo simulacija bazne strategije (bez greške) → Task 3 smoke.
